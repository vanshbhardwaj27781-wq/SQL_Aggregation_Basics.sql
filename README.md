# SQL Aggregation Basics

## 📌 Project Overview

This project demonstrates the basic use of SQL Aggregation Functions using MySQL. It focuses on analyzing student data and calculating different statistics using SQL queries.

## 🎯 Objective

The main objective of this project is to understand and practice SQL aggregate functions such as COUNT, SUM, AVG, MIN, and MAX along with the GROUP BY clause.

## 🛠️ Technologies Used

- MySQL
- SQL

## 📊 Table Used

The project uses a `students` table with the following columns:

| Column | Description |
|--------|-------------|
| student_id | Unique ID of the student |
| name | Name of the student |
| course | Course of the student |
| marks | Marks obtained by the student |

## 🔢 SQL Functions Used

- `COUNT()` – Counts the number of students
- `SUM()` – Calculates the total marks
- `AVG()` – Calculates the average marks
- `MIN()` – Finds the minimum marks
- `MAX()` – Finds the maximum marks
- `GROUP BY` – Groups data based on course
